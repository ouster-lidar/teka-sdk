# Edge Compute & Accessories

These pages cover the connectors, GPIO pins, and reset and recovery steps for a ZED Box running TekaOS.

**New to the box?** Start with [Getting Started](../01_getting-started/01_zed-box-with-tekaos.md). It takes you from a fresh box to your first app.

## Configurations

### Compute module

The ZED Box Mini or ZED Box 2 with TekaOS supports the following [NVIDIA® Jetson™ compute modules](https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/jetson-orin/):

- NVIDIA® Jetson™ Orin NX 16 GB - 157 TOPS

### Connectivity

- 2x [GMSL2](https://www.stereolabs.com/docs/products/embedded/zed-link-capture-card#what-is-gmsl2) FAKRA-Z Connectors
- 1x USB3.0 Type-A
- 1x 10/100/1000 Base-T ethernet RJ45
- Intel AX210 WiFi Module mounted on M.2 Key-E 2230 socket and 2x 2.4/5GHz WiFi antennas
- 1x HDMI 1.4
- 1x Micro USB2.0 Type-B for system flashing & OTG
- 1x [GMSL2](https://www.stereolabs.com/docs/products/embedded/zed-link-capture-card#what-is-gmsl2) Camera Synchronization Trigger Input
- 1x [GMSL2](https://www.stereolabs.com/docs/products/embedded/zed-link-capture-card#what-is-gmsl2) Cameras Synchronization Trigger Output
- 1x 12V Fan Entry
- 1x GPIO port: 1x CAN, 1x UART, 2x general GPIOs, 1x 5V, 1x 3.3V, 2x GND

### Storage memory

An SSD 256GB mounted on an M.2 Key-M 2242 socket is included with all the configurations.
