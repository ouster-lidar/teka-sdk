# Network defaults

Finish [Connect to your ZED Box](../../01_getting-started/02_connect-your-zed-box.md) first. That covers power, the web interface, and your admin password.

- Ethernet gets its address from DHCP.
- The web interface is on port 80. The box answers mDNS. Apps open other ports while they run. See [Box Resources and Firewall](../../02_teka-apps/04_apps-and-packaging/03_box-resources-and-firewall.md).
