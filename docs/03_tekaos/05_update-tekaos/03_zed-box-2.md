# TekaOS on the ZED Box 2

The ZED Box 2, 16GB, 1TB (SKU ZBX-820120) comes with TekaOS installed. It runs on an NVIDIA Jetson Orin NX 16 GB (up to 157 TOPS), with a 1 TB NVMe SSD.

## What's on the box

| Port | Use it for |
| --- | --- |
| 2x Gigabit Ethernet | One for your network, one for your lidar. You don't need a switch. |
| 8x GMSL2 | ZED X cameras |
| 3x USB 3.2 | Drives, keyboards, and other USB devices |
| 1x HDMI 2.1 | A screen |
| 2x CAN (DB9) | Vehicle and machine buses |
| Sync and I/O (DB9) | Hardware sync and one digital input or output |
| Micro USB | Flashing and recovery |

## Get started

Plug in the power supply and an Ethernet cable, then open the web interface and set a password. See [Connect to your ZED Box](../../01_getting-started/02_connect-your-zed-box.md).

## Good to know

- The HDMI screen stays blank unless an app uses it.
- Your box's name comes from the serial number on its label, like teka-gtw-onx2-x11xxxxx.local.
- Want the full hardware specs? See the ZED Box 2 page on the Stereolabs website.
