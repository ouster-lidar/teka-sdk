SSH access

    

    
Paste your public key below before connecting — nothing is authorized at first boot. Login as js — ncu, nsys, tegrastats, nvidia-smi, and compute-sanitizer are on PATH. Use root only when you need privileged host access.

    

        

            js
            ssh -p 2223 js@…
            
        

        

            root
            ssh -p 2223 root@…
            
        

    






    

        
Examples

    

    
ncu --version
nsys --version
tegrastats --interval 1000
nvidia-smi

# Profile a new process
nsys profile ./your-cuda-app

# Attach to a running process (needs root for ptrace)
sudo nsys profile --pid <PID> --duration 30
ncu --target-processes all --set full -o report --attach <PID>

compute-sanitizer --tool memcheck ./your-cuda-app

    
Run ncu-ui / nsys-ui on your workstation for remote profiling; target this device with the CLI tools above.
